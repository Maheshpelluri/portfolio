02 / Freelance · Automation

Non-Attempted Student Automation

Python · Streamlit · Local-only

Every day, someone had to open the assessment export, scan for blanks, match roll numbers against the master roster by hand, and split the result batch by batch. It wasn't hard work — it was slow, repetitive, and easy to get wrong at scale.

This tool matches every roll number against the master roster, flags anything unrecognized, and produces a formatted, batch-split Excel workbook in one pass.

Data stays on the machine. The app runs entirely locally as a Streamlit tool — the master roster never leaves the analyst's own device and is git-ignored by design.

03 / Freelance · Automation

Non-Attempted Register

React · Client-side · Browser tool

The first version of this workflow assumed a fixed number of course files — that assumption broke the moment the file count or column formatting changed. The rebuilt version reads the structure from the data itself: any number of CSV or Excel files, inconsistent header casing and spacing handled automatically, and the correct sheet picked out of multiple sheets per file.

Everything runs client-side in the browser. Nothing is uploaded to a server.
